# 최은미 박사 | 마인드모멘텀

최은미 박사의 공개 유튜브·인스타그램 콘텐츠를 참고해 만든 Next.js App Router 기반 풀스택 홈페이지입니다.

## 구현 내용

- 리더십·조직개발·의사결정 세 축의 반응형 브랜딩 페이지
- YouTube `최은미 박사 | 마인드모멘텀`와 Instagram `@eunmi.effect` 콘텐츠 연결
- 홈페이지 전문가 3인(브랜드 전략가·UX 디렉터·풀스택 아키텍트)의 설계 결과 섹션
- `/api/consult` 문의 검증 API와 성공/실패 피드백
- `/api/health` 상태 확인 API
- 모바일 네비게이션과 탭 인터랙션을 고려한 접근성 마크업

## 시작하기

```bash
pnpm install
pnpm dev
```

프로덕션 빌드:

```bash
pnpm build
pnpm start
```
